              安全说明
              
修改 AT+QCFG="usbcfg" 最后一位（UAC）前会保存旧值以便恢复。更改后通常需软重启才生效。若 AT+QPCMV 返回 ERROR，表示本机固件可能无 UAC/QPCMV——通话控制（拨打/接听/挂断）仍可用，但电脑端可能无声。

            

          

        


        
        

          

            

              

                
WINDOWS DRIVERS

                
一键安装

              

              

                
                
              

            

            
「一键安装驱动」仅装 qcser / qcmdm / qcfilter（串口 AT/DM/filter）。建议顺序：安装驱动 → 检测模块 → 使用短信。

            

              上网驱动说明
              
仓库内无单独的「大疆官方」上网驱动包；本模块实用的 WWAN/NDIS 上网驱动即捆绑的 qcwwan.inf（含 ndis sys）。点击「安装上网驱动」会以管理员权限仅安装 qcwwan。可能覆盖已有的百旺/大疆 WWAN 网卡驱动；若当前已能上网可跳过。
